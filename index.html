Slither catches the bug that cost The DAO $50M

Slither is an open-source static analyzer for Solidity by Trail of Bits. It reads contract code without running it and flags known vulnerability patterns. Below: scan a vulnerable bank, then watch the attack happen live.

3. What Slither flags and how to fix it

    

      
ThreatWhat Slither detectsFix

      
ReentrancyState variable written after an external callChecks-Effects-Interactions, or a reentrancy guard

      
Integer overflowUnchecked arithmetic in old compilersUse Solidity 0.8.0 or newer

      
Timestamp dependenceLogic that branches on block.timestampDo not use block data for randomness or critical timing
